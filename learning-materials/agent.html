CONCEPT · 概念学习资料

AI Agent（智能体）

本资料默认按 AI 领域的「智能体」讲解——一种能自己规划、调用工具、完成任务闭环的 AI 系统。

🎯学习目标

1

能用自己的话讲清「Agent 是什么」，并说清它与普通聊天机器人的区别。

2

能拆解 Agent 的四个核心组成（大模型 / 规划 / 记忆 / 工具），画出它的工作循环。

3

能判断一个真实系统算不算 Agent，并说出它的典型局限与适用边界。

❓带着 3 个核心问题去学

  • 问题一：同样在对话框里打字，为什么有的 AI 只是「聊天」，有的却被称为「Agent」？分界线到底在哪？
  • 问题二：一个 Agent 从接到任务到完成任务，中间经历了哪些环节？每个环节由谁负责？
  • 问题三：「什么都能干」的 Agent 为什么没有完全取代人工？它靠不住的地方在哪？

学完后试着用这三句话自检：能不能答上来、能不能举例、能不能反驳。

💡个人化解释：把 Agent 当成「有手有脑的实习生」

把 AI 想象成人，区分就清楚了：

  • 普通聊天机器人像一个「只能聊天的顾问」——你问一句，它答一句。它不会主动去查资料、不会动手干活，聊完就结束。
  • Agent（智能体）则像一个「有手有脑的实习生」——你交给它一个目标（比如「帮我整理本月时政热点」），它会自己琢磨该分几步做：先上网搜 → 再筛选 → 再排版 → 中途发现材料不够还会回头再搜 → 最后把成品交给你。整个过程不需要你一步步指挥。
一句话记忆：聊天机器人回答你，Agent 替你办事。Agent = 大模型这颗「大脑」+ 能动手的「工具」+ 自己安排步骤的「主动性」。

⚙️核心机制与组成拆解

① 它的工作循环（Agentic Loop）

Agent 的本质是一个「感知 → 思考 → 行动 → 观察 → 再思考」的循环，直到目标达成或主动停下：

🎯 目标输入
→
🧠 规划
拆解任务、决定下一步
→
🛠️ 行动
调用工具/检索/执行
→
👀 观察
读取工具返回结果
→
✅ 完成 / 继续
循环的关键：每一步的结果都会喂回给大模型，用来修正下一步——这叫「让模型自己决定路径」。

② 四个核心组成

🧠 大模型（大脑）
负责理解、推理与决策：读任务、想方案、判断结果好不好。是整个 Agent 的「控制器」。
🗺️ 规划（路径）
把大目标拆成小步骤（任务分解），常见方法如 ReAct（边推理边行动）、思维链等。遇到错误能反思、调整计划。
🧾 记忆（档案）
短期记忆=当前对话上下文；长期记忆=存到外部（向量数据库、知识库），下次还能调用。
🔧 工具（手脚）
搜索、查数据库、写代码、发消息、操作软件……模型通过「函数调用」使用工具，MCP 则是给工具统一接口的协议。

③ 为什么现在才火起来

2022 年后大模型有了更强的推理能力和函数调用（Function Calling）能力——模型不只是输出文字，还能按格式「申请调用某个工具」，这是 Agent 能动手的关键前提。之后出现了一批代表框架与研究：ReAct（2022）、AutoGPT（2023）、LangChain / AutoGen / CrewAI、OpenAI Agents SDK、Anthropic 的 MCP 协议等。

🚀一个具体应用场景：AI 备考学伴

假设你正在备考，想搭建一个「时政热点整理 Agent」，你只需要给它一个目标，它自己走完这套流程：

1
接收目标：「整理本周与申论、新传相关的时政热点，每条约 200 字，标注可用论点。」
2
规划拆解：搜新闻 → 按主题聚类 → 筛掉无关资讯 → 撰写条目 → 输出卡片。
3
行动 + 观察：调用新闻搜索工具 → 发现某条来源存疑 → 换关键词再搜核实 → 结果合格才采用。
4
交付：生成带「事件 / 背景 / 意义 / 可用论点」结构的素材卡片，存入你的笔记体系，供申论与专业课共用。
这个场景里，Agent 的价值是把「搜集—筛选—整理」这类重复劳动自动化，让你把时间花在真正需要判断力的地方——比如论点怎么用、材料怎么组织。

⚠️容易混淆的地方 & 使用边界

① 四组高频混淆概念

概念关键区别
Agent vs 聊天机器人聊天机器人是「一问一答」；Agent 能自主规划、调用工具、多轮迭代直到完成任务。
Agent vs 工作流（Workflow）工作流是「写死的固定流程」（如：抓取→清洗→输出）；Agent 由模型每次动态决定走哪条路。工作流可控但死板，Agent 灵活但难预测。
Agent vs RAG 问答RAG（检索增强生成）只是「先查资料再回答」，通常没有行动循环；Agent 可以反复查询、操作、验证。
AI 的 Agent vs 传播学里的 agent在传播学/社会学语境（如行动者网络理论）中 agent 常指「行动者/能动者」，含义完全不同。看资料时先分清语境，别混用。

② 使用边界：Agent 目前靠不住的地方

  • 幻觉与事实错误：模型可能自信地编造信息，涉及数据、法条、政策原文时必须人工核验。
  • 长任务会「跑偏」：步骤越多，错误越容易累积，可能绕圈子或半途而废，需要设置上限与检查点。
  • 成本与速度：自主循环意味着多次调用模型和工具，比单次问答更贵、更慢。
  • 安全与权限：让 AI 动手操作真实系统有风险，应遵循最小权限，关键操作保留「人在环」（人工确认）。
  • 适用范围：结果可验证、步骤可拆解、环境可交互的任务适合 Agent；一次性的简单问答、需要高度创意或极高准确率的场合未必划算。
记住这句判断口诀：「能交给 Agent 的，是那些你愿意反复检查的任务」——自主不等于可靠，边界感才是用好它的关键。

📝3 道自测题（点选项查看结果）

第 1 题下列哪一项最能体现「Agent」与普通聊天机器人的本质区别？
A. Agent 的回复措辞更专业、更像真人
B. Agent 能自主规划步骤并调用工具，迭代推进直到完成任务
C. Agent 的回答永远正确、不会出错
D. Agent 可以离线运行，不需要联网
解析区别的核心在「能不能自己动手干完一件事」——规划 + 工具调用 + 循环迭代，而不是语气或正确率（C、D 本身是常见误解）。
第 2 题在 Agent 的「感知—规划—行动—观察」循环中，哪一环通常由大语言模型承担？
A. 只有「行动」环节，工具调用全由模型完成
B. 只有「观察」环节，读取结果是模型的本职
C. 规划与决策环节——模型作为「大脑」决定下一步做什么
D. 以上所有环节都只能靠外部代码，模型不参与
解析大模型是 Agent 的「控制器」：理解目标、做规划、判断结果都由它负责；行动要靠工具，观察靠读取工具返回，但这些决策都出自模型。
第 3 题关于 Agent 的「记忆」，下列说法正确的是？
A. 短期记忆≈上下文窗口；长期记忆通常存放在外部（如向量数据库），可供后续任务复用
B. Agent 不需要记忆，每次任务都从零开始最可靠
C. 记忆只指模型的训练数据，与当前任务无关
D. 上下文窗口无限大，长期记忆永远装得下
解析上下文窗口有限，跨任务、跨会话的信息要靠外部存储（向量库、知识库等）实现长期记忆；B、C、D 都是对记忆机制的误解。

  1. Anthropic：Building Effective Agents（官方工程指南） 业界权威的 Agent 与工作流辨析，给出了「何时该用 Agent、何时该用工作流」的判断标准。

  5. Microsoft AutoGen 官方文档 多智能体（Multi-Agent）协作框架的代表，了解多个 Agent 如何分工合作。
