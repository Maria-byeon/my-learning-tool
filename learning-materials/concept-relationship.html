Agent、大模型的上下文、Skill
三者关系

上下文提供"视野"，Skill 提供"方法"，Agent 是那个真正动手的执行者。

🧩三位各是什么

大模型的上下文
信息环境

Agent 工作时可用的信息环境和工具，决定了 Agent 能获取什么知识。

Agent
执行者

根据上下文做决策和行动的智能体，它是那个做事的执行者。

Skill
方法库

固化下来的标准操作流程，让 Agent 能稳定复用特定任务的经验。

🔗它们怎么配合

一句话记住分工：上下文给 Agent 提供"视野"，Skill 给 Agent 提供"方法"，最后由 Agent 完成决策与行动。

放大任何一个，Agent 都更强：上下文越大，Agent 能处理的信息越多；Skill 越完善，Agent 做事越专业。三者共同决定 Agent 的实际表现。
💡
一句话总结

上下文决定 Agent 能看见什么，Skill 决定 Agent 会怎么干， Agent 自己决定 干不干、干什么——三者缺一，表现都会打折扣。
